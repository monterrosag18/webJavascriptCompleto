📦 Arrays

Métodos que MODIFICAN
arr.push(4) // Añade al final arr.pop() // Quita del final arr.unshift(0) // Añade al inicio arr.shift() // Quita del inicio arr.splice(1,2) // Elimina/inserta arr.reverse() // Invierte arr.sort() // Ordena
Métodos que NO modifican
arr.map(x => x * 2) // Transforma arr.filter(x => x > 2) // Filtra arr.find(x => x > 2) // Busca primero arr.findIndex(x => x > 2)// Índice arr.some(x => x > 2) // ¿Alguno? arr.every(x => x > 2) // ¿Todos? arr.includes(3) // ¿Contiene? arr.reduce((a,b) => a+b) // Acumula
⭐ Reduce - El más importante
// Suma [1,2,3].reduce((acc, val) => acc + val, 0) // 6 // Agrupar users.reduce((grupos, user) => { (grupos[user.role] ||= []).push(user); return grupos; }, {}) // Contar letras.reduce((count, l) => ({ ...count, [l]: (count[l] || 0) + 1 }), {})

🎯 Objetos

Creación y Acceso
const obj = { nombre: "Ana", edad: 25 }; obj.nombre // "Ana" obj["nombre"] // "Ana" obj.ciudad = "BCN" // Añadir delete obj.edad // Eliminar // Comprobar propiedad "nombre" in obj // true obj.hasOwnProperty("nombre") // true
Métodos útiles
Object.keys(obj) // ["nombre", "edad"] Object.values(obj) // ["Ana", 25] Object.entries(obj) // [["nombre","Ana"],...] // Copiar const copia = { ...obj }; const copia2 = Object.assign({}, obj); // Mezclar const merged = { ...obj1, ...obj2 };

Arrays

Objetos

⚡ Funciones

// Declaración function sumar(a, b) { return a + b; } // Expresión const sumar = function(a, b) { return a + b; }; // Arrow function const sumar = (a, b) => a + b; const cuadrado = x => x * x; // Un parámetro sin () const saludar = () => "Hola"; // Sin parámetros // Parámetros default const saludo = (nombre = "Mundo") => `Hola ${nombre}`; // Rest parameters const sumarTodos = (...nums) => nums.reduce((a,b) => a+b, 0);

⏳ Async/Await & Promises

Promises
const promise = new Promise((resolve, reject) => { // async operation resolve(data); // ✅ Éxito reject(error); // ❌ Error }); promise .then(data => console.log(data)) .catch(err => console.error(err)) .finally(() => console.log("Fin"));
Async/Await
async function fetchData() { try { const res = await fetch(url); const data = await res.json(); return data; } catch (error) { console.error(error); } } // Paralelo const [a, b] = await Promise.all([p1, p2]);
