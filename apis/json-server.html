JSON Server

Crea una API REST falsa completa en menos de 30 segundos

¿Qué es JSON Server?

JSON Server es una herramienta que te permite crear una API REST completa a partir de un simple archivo JSON. Es perfecta para:

  • Prototipar aplicaciones frontend rápidamente
  • Aprender a consumir APIs REST
  • Hacer pruebas sin backend real
  • Mockear datos para desarrollo
Características
  • GET, POST, PUT, PATCH, DELETE
  • Filtrado y ordenamiento
  • Paginación
  • Búsqueda full-text
  • Relaciones entre datos
  • Persistencia automática

1Instalación

Necesitas tener Node.js instalado en tu computadora.
Instalación Global (recomendada)
$ npm install -g json-server
Instalación en proyecto
$ npm install json-server --save-dev
Verificar instalación
$ json-server --version

3Iniciar el Servidor

Comando básico
$ json-server --watch db.json
Con puerto personalizado
$ json-server --watch db.json --port 3001
Opciones comunes
# Puerto personalizado $ json-server db.json --port 5000 # Delay en respuestas (simular latencia) $ json-server db.json --delay 1000 # Host personalizado $ json-server db.json --host 0.0.0.0 # Rutas personalizadas $ json-server db.json --routes routes.json # Combinado $ json-server db.json --watch --port 3001 --delay 500
Script en package.json
{
    "scripts": {
        "server": "json-server --watch db.json --port 3001",
        "dev": "concurrently \"npm run server\" \"npm start\""
    }
}
¡Listo! El servidor estará corriendo en http://localhost:3000

5Filtrado, Ordenamiento y Paginación 

// Filtrar por campo exacto
GET /usuarios?activo=true
GET /productos?categoria=electronica

// Filtrar por múltiples campos
GET /productos?categoria=electronica&stock_gte=10

// Operadores de comparación
GET /productos?precio_gte=100      // >= 100
GET /productos?precio_lte=500      // <= 500
GET /productos?precio_gt=100       // > 100
GET /productos?precio_lt=500       // < 500
GET /productos?precio_ne=299       // != 299

// Filtrar por rango
GET /productos?precio_gte=100&precio_lte=500

// Búsqueda en texto (case insensitive)
GET /usuarios?nombre_like=juan

// Búsqueda full-text (todos los campos)
GET /usuarios?q=juan

// Ordenar ascendente
GET /productos?_sort=precio

// Ordenar descendente
GET /productos?_sort=precio&_order=desc

// Ordenar por múltiples campos
GET /productos?_sort=categoria,precio&_order=asc,desc

// Ejemplos prácticos
// Productos más baratos primero
GET /productos?_sort=precio&_order=asc

// Usuarios más recientes (por ID)
GET /usuarios?_sort=id&_order=desc

// Ordenar alfabéticamente
GET /productos?_sort=nombre&_order=asc

// Paginación básica
GET /productos?_page=1&_limit=10

// Segunda página
GET /productos?_page=2&_limit=10

// Solo limitar resultados
GET /productos?_limit=5

// Slice (inicio, fin)
GET /productos?_start=0&_end=10
GET /productos?_start=10&_end=20

// El header X-Total-Count contiene el total
// de registros para calcular páginas

// JavaScript para paginación
async function fetchPage(page, limit = 10) {
    const response = await fetch(
        `http://localhost:3000/productos?_page=${page}&_limit=${limit}`
    );
    
    const total = response.headers.get('X-Total-Count');
    const totalPages = Math.ceil(total / limit);
    const data = await response.json();
    
    return { data, total, totalPages, currentPage: page };
}

6Ejemplo Completo: CRUD con JSON Server 

// ============================================
// API SERVICE PARA JSON SERVER
// ============================================

const API_URL = 'http://localhost:3000';

class ApiService {
    constructor(resource) {
        this.endpoint = `${API_URL}/${resource}`;
    }
    
    // ===== GET ALL =====
    async getAll(params = {}) {
        const query = new URLSearchParams(params).toString();
        const url = query ? `${this.endpoint}?${query}` : this.endpoint;
        
        const response = await fetch(url);
        
        if (!response.ok) {
            throw new Error(`Error: ${response.status}`);
        }
        
        const data = await response.json();
        const total = response.headers.get('X-Total-Count');
        
        return { data, total: total ? parseInt(total) : data.length };
    }
    
    // ===== GET BY ID =====
    async getById(id) {
        const response = await fetch(`${this.endpoint}/${id}`);
        
        if (!response.ok) {
            if (response.status === 404) {
                throw new Error('Recurso no encontrado');
            }
            throw new Error(`Error: ${response.status}`);
        }
        
        return response.json();
    }
    
    // ===== CREATE =====
    async create(data) {
        const response = await fetch(this.endpoint, {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(data)
        });
        
        if (!response.ok) {
            throw new Error('Error al crear');
        }
        
        return response.json();
    }
    
    // ===== UPDATE (PUT - reemplaza todo) =====
    async update(id, data) {
        const response = await fetch(`${this.endpoint}/${id}`, {
            method: 'PUT',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(data)
        });
        
        if (!response.ok) {
            throw new Error('Error al actualizar');
        }
        
        return response.json();
    }
    
    // ===== PATCH (actualización parcial) =====
    async patch(id, data) {
        const response = await fetch(`${this.endpoint}/${id}`, {
            method: 'PATCH',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(data)
        });
        
        if (!response.ok) {
            throw new Error('Error al actualizar');
        }
        
        return response.json();
    }
    
    // ===== DELETE =====
    async delete(id) {
        const response = await fetch(`${this.endpoint}/${id}`, {
            method: 'DELETE'
        });
        
        if (!response.ok) {
            throw new Error('Error al eliminar');
        }
        
        return true;
    }
    
    // ===== BÚSQUEDA =====
    async search(query) {
        return this.getAll({ q: query });
    }
    
    // ===== CON PAGINACIÓN =====
    async paginate(page = 1, limit = 10, filters = {}) {
        const params = {
            _page: page,
            _limit: limit,
            ...filters
        };
        return this.getAll(params);
    }
}

// ============================================
// USO DEL API SERVICE
// ============================================

// Crear instancias para cada recurso
const usuariosApi = new ApiService('usuarios');
const productosApi = new ApiService('productos');
const pedidosApi = new ApiService('pedidos');

// Obtener todos los usuarios
const { data: usuarios } = await usuariosApi.getAll();

// Obtener usuario por ID
const usuario = await usuariosApi.getById(1);

// Crear nuevo usuario
const nuevoUsuario = await usuariosApi.create({
    nombre: 'Ana Torres',
    email: 'ana@email.com',
    edad: 27,
    activo: true
});

// Actualizar usuario
await usuariosApi.patch(1, { activo: false });

// Eliminar usuario
await usuariosApi.delete(3);

// Buscar productos
const { data: results } = await productosApi.search('laptop');

// Paginar productos
const { data, total } = await productosApi.paginate(1, 10, {
    _sort: 'precio',
    _order: 'desc'
});

// Filtrar por categoría
const electronica = await productosApi.getAll({
    categoria: 'electronica',
    _sort: 'precio'
});

7Rutas Personalizadas

Crea un archivo routes.json para personalizar las rutas:

{
    "/api/*": "/$1",
    "/api/v1/*": "/$1",
    "/users/:id": "/usuarios/:id",
    "/products": "/productos",
    "/products/:id": "/productos/:id"
}

// Ejecutar con rutas personalizadas:
// json-server db.json --routes routes.json

// Ahora puedes usar:
// GET /api/usuarios  -> /usuarios
// GET /api/v1/productos  -> /productos
// GET /users/1  -> /usuarios/1
Tip: Middleware Personalizado
