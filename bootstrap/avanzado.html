1. Glassmorphism (Efecto Cristal)

Efecto de vidrio esmerilado muy popular en diseño moderno. Usa backdrop-filter: blur()

Clima Actual

24°C

Ciudad de México

<!-- Contenedor con fondo animado -->
<div class="animated-background p-5">
    <!-- Card con efecto glass -->
    <div class="glass-card text-center">
        <i class="bi bi-cloud-sun display-4 mb-3"></i>
        <h4>Clima Actual</h4>
        <p class="display-3 fw-bold mb-0">24°C</p>
        <p class="opacity-75">Ciudad de México</p>
    </div>
</div>
/* Efecto Glassmorphism */
.glass-card {
    /* Fondo semitransparente */
    background: rgba(255, 255, 255, 0.1);
    
    /* El efecto blur - CLAVE del glassmorphism */
    backdrop-filter: blur(10px);
    -webkit-backdrop-filter: blur(10px); /* Safari */
    
    /* Borde sutil */
    border: 1px solid rgba(255, 255, 255, 0.2);
    
    /* Bordes redondeados */
    border-radius: 20px;
    padding: 30px;
    color: white;
}

/* Fondo animado con gradiente */
.animated-background {
    background: linear-gradient(-45deg, #ee7752, #e73c7e, #23a6d5, #23d5ab);
    background-size: 400% 400%;
    animation: gradient 15s ease infinite;
}

@keyframes gradient {
    0% { background-position: 0% 50%; }
    50% { background-position: 100% 50%; }
    100% { background-position: 0% 50%; }
}

2. Bordes con Gradiente

Técnica con pseudo-elemento para crear bordes con gradiente

✨ Card Premium

Esta card tiene un borde con gradiente usando la técnica del pseudo-elemento

/* Borde gradiente con pseudo-elemento */
.gradient-border {
    position: relative;
    background: white;
    border-radius: 16px;
    padding: 30px;
}

/* El pseudo-elemento crea el "borde" */
.gradient-border::before {
    content: '';
    position: absolute;
    /* inset negativo = más grande que el padre */
    inset: -3px; /* grosor del borde */
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    border-radius: 18px; /* un poco más que el padre */
    z-index: -1; /* detrás del contenido */
}

/* Versión alternativa con border-image (menos soporte) */
.gradient-border-alt {
    border: 3px solid;
    border-image: linear-gradient(135deg, #667eea, #764ba2) 1;
    border-radius: 16px; /* No funciona con border-image */
}

3. Efectos Hover Avanzados

Cards interactivas con múltiples efectos hover

Hover Lift

Se eleva al pasar el mouse

Hover Scale

Se agranda al pasar el mouse

Hover Rotate

Rota ligeramente

/* 1. Hover Lift - Elevación */
.hover-lift {
    transition: all 0.3s ease;
}
.hover-lift:hover {
    transform: translateY(-10px);
    box-shadow: 0 20px 40px rgba(0,0,0,0.15);
}

/* 2. Hover Scale - Agrandar */
.hover-scale {
    transition: transform 0.3s ease;
}
.hover-scale:hover {
    transform: scale(1.05);
}

/* 3. Hover Rotate - Rotar */
.hover-rotate {
    transition: transform 0.3s ease;
}
.hover-rotate:hover {
    transform: rotate(2deg);
}

/* 4. Hover Glow - Resplandor */
.hover-glow {
    transition: box-shadow 0.3s ease;
}
.hover-glow:hover {
    box-shadow: 0 0 30px rgba(102, 126, 234, 0.5);
}

/* 5. Hover Border Color */
.hover-border {
    border: 2px solid transparent;
    transition: border-color 0.3s ease;
}
.hover-border:hover {
    border-color: #667eea;
}

4. Skeleton Loaders

Placeholders animados mientras carga el contenido

/* CSS del Skeleton Loader */
.skeleton {
    background: linear-gradient(90deg, 
        #f0f0f0 25%, 
        #e0e0e0 50%, 
        #f0f0f0 75%
    );
    background-size: 200% 100%;
    animation: skeleton 1.5s infinite;
    border-radius: 4px;
}

@keyframes skeleton {
    0% { background-position: 200% 0; }
    100% { background-position: -200% 0; }
}

/* HTML de uso */
<div class="card">
    <!-- Imagen skeleton -->
    <div class="skeleton" style="height: 180px;"></div>
    
    <div class="card-body">
        <!-- Título skeleton -->
        <div class="skeleton mb-2" style="height: 20px; width: 70%;"></div>
        
        <!-- Texto skeleton -->
        <div class="skeleton mb-2" style="height: 14px;"></div>
        <div class="skeleton" style="height: 14px; width: 80%;"></div>
    </div>
</div>

/* JavaScript para reemplazar skeleton con datos reales */
async function loadData() {
    const data = await fetch('/api/data').then(r => r.json());
    
    // Reemplazar skeletons con contenido real
    document.querySelector('.skeleton-title').innerHTML = data.title;
    document.querySelector('.skeleton-title').classList.remove('skeleton');
}
