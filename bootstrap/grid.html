Sistema Grid de Bootstrap 5

El sistema más potente para crear layouts responsivos

¿Cómo Funciona el Grid?

Conceptos Clave
  • Container: Contenedor que centra y limita el ancho
  • Row: Fila que contiene las columnas
  • Col: Columna (12 columnas máximo por fila)
  • Breakpoints: Puntos de quiebre responsivos
Sistema de 12 Columnas

El grid se divide en 12 columnas. Puedes combinar diferentes anchos que sumen 12, o usar columnas automáticas.

Breakpoints (Puntos de Quiebre)

Breakpoint Prefijo Dimensiones Ejemplo
Extra pequeño - (ninguno) <576px col-12
Pequeño sm ≥576px col-sm-6
Mediano md ≥768px col-md-4
Grande lg ≥992px col-lg-3
Extra Grande xl ≥1200px col-xl-2
XXL xxl ≥1400px col-xxl-1
